# План реализации папочной структуры белого списка

## 1. Информативный экран при включенном «Разрешить все контакты»
- Если белый список пуст, но включен переключатель «Разрешить все контакты»:
  - Отображается специальный статус:
    - **Иконка**: телефонная книга / щит с контактами.
    - **Заголовок**: «Контакты разрешены».
    - **Описание**: «Все контакты из вашей телефонной книги имеют доступ. Вы можете создать папки (группы) и добавить номера, которых нет в записной книжке.»

## 2. Истинная структура «Папок» (Групп)
- **Концепция папок**:
  - Экран «Белый список» отображает список **Папок (Групп)** в виде карточек/аккордеонов (или интерактивных папок).
  - У каждой папки есть:
    - Название папки.
    - Переключатель активности (Вкл/Выкл — звонки из выключенной папки блокируются).
    - Счетчик контактов (например, `5 контактов`).
    - Кнопка разворачивания/просмотра номеров внутри этой папки.
    - Быстрое добавление номера внутрь конкретной папки.
    - Кнопки переименования и удаления папки (с номерами).
- **Автоматическое создание группы**:
  - При первом запуске или добавлении первого контакта, если нет ни одной группы, автоматически создается группа **«Основная»** (или папка по выбору пользователя).
  - Каждый контакт всегда привязан к конкретной папке (`groupId`).
  - Убираются лишние плоские фильтры («Все», «Основной»).
