# План доработки виджета и темы оформления

## 1. Цветовая палитра и выделение пиктограмм на светлой теме
- Обновление цветов в `Color.kt` и `Theme.kt`:
  - Мягкий, пастельный светлый тон для активных бейджей (`#DCFCE7` / `#E8F5E9`) с темно-зеленым текстом (`#166534`).
  - Улучшение контраста и читаемости всех цветных плашек в светлой теме.

## 2. Кнопка питания на виджете
- Замена иконки «обновить» на понятную классическую кнопку питания (`ic_power` / Power Button):
  - Зеленая светящаяся кнопка при включенной защите.
  - Серая/красная кнопка при выключенной защите.

## 3. Сверхкомпактный виджет 2x1
- Полная переработка разметки `widget_white_call.xml`:
  - Плотная 2x1 компоновка без пустых полей.
  - Компактный бейдж со счетчиком (например, `🛡 0` или `Блок: 5`).
  - Удобная кнопка переключения справа.

## 4. Индикация и мигание зеленой трубки при отклоненном вызове
- Создание векторной иконки зеленой телефонной трубки `ic_phone_incoming.xml`.
- При перехвате вызова в `WhiteCallScreeningService.kt`:
  - Запуск эффекта мигания/пульсации зеленой трубки с номером звонящего на виджете (серия циклов обновления с интервалом для эффекта активности), фиксируя последний звонок.
