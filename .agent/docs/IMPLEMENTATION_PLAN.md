# План доработок WhiteCall (Группы, Темы, UI и Журнал)

## 1. Группы в белом списке
- **База данных Room**:
  - Новая сущность `GroupEntity` (`id`, `name`, `isActive`, `createdAt`).
  - Обновление `WhiteListEntity`: поле `groupId: Long?` (с возможностью перемещения номера в группу).
  - DAO: `GroupDao` (CRUD операции, переключение статуса активности группы).
- **Логика блокировки**:
  - Если номер привязан к группе, вызов разрешается, только если группа активна (`isActive == true`). Номера без группы (или в активных группах) разрешаются.
- **Интерфейс «Белый список»**:
  - Панель фильтрации/вкладок по группам: «Все», «Основной», «Семья», «Работа» и т.д.
  - Меню по кнопке «+»: «Добавить из контактов», «Ввести вручную», «Создать группу».
  - Диалог создания/редактирования/удаления группы, переключатель активности группы (вкл/выкл всю группу одним тапом).

## 2. Переключение тем оформления (Светлая / Темная / Системная)
- Добавление настройки `appTheme` в `AppPreferences`:
  - `system` (системная по умолчанию)
  - `dark` (темная)
  - `light` (светлая)
- Применение в `Theme.kt` и `MainActivity.kt`.
- Блок выбора темы в «Настройках».

## 3. Исправление видимости и контрастности переключателей (Switch)
- Приведение всех переключателей в приложении (`Switch`) к единой цветовой схеме Material 3 с ярким контрастным цветом активного состояния (Primary/Emerald) и четким отображением трека/ползунка.

## 4. Ограничение размера журнала (Автоочистка)
- Добавление автоматического лимита записей в журнале (хранение последних 500 записей / удаление записей старше 30 дней) при добавлении новых записей.
- Отображение текущего размера в настройках с возможностью очистки.

## 5. Мгновенное обновление статуса в журнале блокировок
- При нажатии «+» на записи в журнале:
  - Номер добавляется в белый список.
  - В карточке журнала статус мгновенно меняется на «В белом списке» (зеленый бейдж с галочкой), а кнопка «+» скрывается.
  - Проверка белого списка в реальном времени при отображении элементов журнала.
