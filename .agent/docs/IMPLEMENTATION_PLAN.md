# План доработки виджета и логики звонков

## 1. Удержание номера на виджете на всё время звонка (до конца дозвона)
- Использование системного `TelephonyCallback` / `PhoneStateListener` для отслеживания состояния телефонной линии (`CALL_STATE_RINGING` -> `CALL_STATE_IDLE`).
- Номер и зеленая трубка на виджете отображаются **ровно столько, сколько звонящий совершает дозвон** (гудки). Как только звонящий сбрасывает трубку (`CALL_STATE_IDLE`), виджет мгновенно переключается обратно на счетчик/статус.

## 2. Гарантированное переключение «WC» -> «WhiteCall»
- Корректировка порогов ширины в `onAppWidgetOptionsChanged`: при ширине >= 150dp (3 клетки и шире) всегда активируется полное название `WhiteCall`, а при ширине < 150dp (2 клетки) — компактное `WC`.

## 3. Логика счетчика заблокированных
- Сейчас счетчик считает заблокированные звонки **за текущие сутки (с 00:00)**.
- Добавим в виджет четкую подпись: `Сегодня: N` или `За день: N` (а в 2-уровневом виджете — полную статистику: за сегодня и всего в белом списке).

## 4. Богатый 2-уровневый виджет (при высоте 2 строки / 5x2, 4x2, 3x2, 2x2)
- При увеличении виджета по высоте (2 уровня) отображается подробный дашборд:
  - **Верхняя строка**: Щит + `WhiteCall` + статус защиты («Защита активна» / «По расписанию») + крупная кнопка питания `[ ⏻ ]`.
  - **Средняя строка**: `🛡️ Заблокировано сегодня: N` • `👥 В белом списке: M номеров`.
  - **Нижняя строка**: `🚫 Последний вызов: <Имя/Номер> • <Время>` с быстрым переходом в журнал.
