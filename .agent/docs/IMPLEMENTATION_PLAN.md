# План реализации адаптивного виджета и режимов блокировки

## 1. Адаптивный виджет под разные размеры (2x1 и 5x2)
- **Компактный режим (2х1)**:
  - Строка 1: `🛡️ WC` (без переноса строк, `singleLine="true"`).
  - Строка 2: `Блок: 0` (или `📞 +7 999...` при звонке / последний заблокированный).
  - Справа: компактная кнопка питания `⏻`.
- **Расширенный режим (от 3х1 до 5х2)**:
  - Крупные элементы и типографика (18sp заголовок, крупные иконки 36-48dp).
  - Полное название `WhiteCall`, статус защиты, бейдж `🛡️ Заблокировано: N`.
  - Отображение последнего звонка: `📞 <Номер/Имя> • <Время>` (зеленая трубка).
  - Крупная кнопка питания `⏻` справа.
- **Отображение трубки звонка**:
  - Зеленая трубка мигает во время входящего вызова и сохраняется в строке виджета как «Последний звонок: <номер/время>».

## 2. Новый режим работы: «Сброс вызова» vs «Беззвучный режим (гудки звонящему)»
- В `CallScreeningService` добавление двух режимов:
  1. **Сброс вызова (Reject)**: `setDisallowCall(true)`, `setRejectCall(true)` — звонящий сразу слышит «Занято».
  2. **Беззвучный пропуск (Silence)**: `setSilenceCall(true)`, `setSkipNotification(true)` — звонящий слышит обычные длинные гудки, но на телефоне экран не загорается, звук и звонилка не появляются, звонок пишется только в журнал и на виджет.
- В «Настройки» добавляется переключатель/селектор режима блокировки с понятными описаниями.
