# План реализации Android-приложения "WhiteCall" (White List Call Blocker)

## Описание проекта
WhiteCall — полнофункциональное, готовое к релизу Android-приложение на Kotlin для блокировки входящих звонков по принципу «Белого списка». Неразрешенные вызовы бесшумно отклоняются на уровне системы до пробуждения экрана и звонка с помощью `CallScreeningService`.

## Архитектура
- **Язык**: Kotlin
- **Min SDK**: API 24 (Android 7.0 Nougat)
- **Target / Compile SDK**: API 34+
- **Архитектура**: Clean Architecture + MVVM
- **UI**: Jetpack Compose + Material Design 3
- **БД**: Room Database (Белый список и Журнал заблокированных)
- **Хранилище**: DataStore / SharedPreferences
- **Фоновый фильтр**: `android.telecom.CallScreeningService`
- **Виджет**: AppWidget 2x1 с быстрым переключением статуса, счетчиком блокировок за сегодня и блоком последнего заблокированного звонка (номер + время).
- **i18n**: Английский + Русский языки

## Шаги реализации:
1. **Настройка Gradle и манифеста**: `build.gradle.kts` (root и app), `settings.gradle.kts`, `gradle.properties`, `AndroidManifest.xml` с объявлением сервисов, виджетов и разрешений.
2. **Векторная графика (XML)**: Адаптивная иконка (щит + галочка/телефон), иконки для навигации, действий и статусов.
3. **Слой данных (Data Layer)**:
   - Сущности Room: `WhiteListEntity`, `BlockedCallEntity`
   - DAO: `WhiteListDao`, `BlockedCallDao`
   - База данных: `AppDatabase`
   - Хранилище настроек: `AppPreferences`
   - Репозитории: `WhiteListRepository`, `CallBlockingRepository`
4. **Слой доменной логики (Domain Layer)**:
   - Модели данных
   - Use cases: нормализация номеров (`NormalizePhoneNumberUseCase`), проверка условий блокировки (`ShouldBlockCallUseCase`), проверка расписания
5. **Фоновый сервис (CallScreeningService)**:
   - `WhiteCallScreeningService` с перехватом звонков, сверкой с БД и контактами, бесшумным отклонением и записью в журнал.
   - Мгновенное обновление виджета с информацией о последнем отклоненном звонке.
6. **Виджет рабочего стола (AppWidget)**:
   - `WhiteCallWidgetProvider`, разметка `widget_white_call.xml`, интерактивное переключение статуса, счетчик заблокированных за сегодня и отображение последнего заблокированного вызова.
7. **Пользовательский интерфейс (UI - Jetpack Compose)**:
   - Тема и стили (Material 3 Dark/Light)
   - Вкладка 1: Белый список (контакты, ручной ввод, свайп/удаление, переключатель "все контакты")
   - Вкладка 2: Журнал блокировок (список, очистка, быстрое добавление в белый список)
   - Вкладка 3: Настройки и справка (назначение роли Call Screening, расписание с пикерами времени и дней, переключатель языка, экспорт/импорт в JSON, FAQ для китайских OEM прошивок)
8. **Вспомогательные утилиты**:
   - Утилиты выбора контактов, экспорта/импорта JSON, смены локали (`AppCompatDelegate`).
9. **Тестирование и проверка**:
   - Unit-тесты для нормализации номеров и логики расписания.
   - Фиксация изменений в Git.
