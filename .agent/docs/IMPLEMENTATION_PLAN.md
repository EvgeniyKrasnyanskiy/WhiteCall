# [Выполнено] План доработок виджетов, кнопок, журнала и контактов

## 1. Превью виджета при добавлении на экран
- **Проблема**: В меню добавления виджетов лаунчера отсутствует превью, отображается серая заглушка.
- **Решение**:
  - Создать векторный макет `app/src/main/res/drawable/widget_preview.xml` с темной карточкой виджета WhiteCall.
  - В `app/src/main/res/xml/widget_info.xml` добавить:
    - `android:previewLayout="@layout/widget_white_call_compact"` (для Android 12+ / API 31+).
    - `android:previewImage="@drawable/widget_preview"` (для Android 11 и ниже).

---

## 2. Исправление стрелок на кнопках экспорта и импорта
- **Проблема**: В `ic_export.xml` стрелка направлена вниз (как импорт/скачивание), а в `ic_import.xml` — вверх (как экспорт/выгрузка).
- **Решение**:
  - Поменять векторные пути (`pathData`) местами в `app/src/main/res/drawable/ic_export.xml` (стрелка вверх) и `app/src/main/res/drawable/ic_import.xml` (стрелка вниз).

---

## 3. Сокращение статусов на виджетах (до 10-11 символов)
- **Проблема**: Тексты «Защита активна», «Активно по расписанию» (21 символ) и «Защита отключена» не помещаются на ячейках виджета.
- **Решение**:
  - Добавить специализированные строки в `strings.xml` (RU: `Активен`, `Отключён`, `Расписание`; EN: `Active`, `Disabled`, `Schedule`).
  - Использовать их в `WhiteCallWidgetProvider.kt` и макетах виджетов (`widget_white_call_*.xml`).

---

## 4. Кнопка удаления из белого списка на карточке вызова в истории
- **Проблема**: На карточке вызова есть кнопка добавления `+`, но если номер уже в белом списке, кнопки удаления нет.
- **Решение**:
  - Добавить `removeFromWhiteList(phoneNumber: String)` в `BlockedLogViewModel`.
  - В `BlockedLogItem`: если номер уже в белом списке (`isWhitelisted == true`), показывать кнопку удаления с иконкой `ic_delete` и открывать подтверждение/действие удаления.
  - В диалоге действий `targetForActionDialog`: если контакт в белом списке, отображать опцию «Удалить из белого списка» с красной иконкой корзины.

---

## 5. Имя контакта для заблокированного номера
- **Ответ на вопрос**: Если номер есть в контактах устройства, но не в белом списке, при блокировке его имя уже извлекается через `ContactHelper` и записывается в лог.
- **Улучшение**: Добавить в `BlockedLogViewModel` автоматическую подгрузку имени из контактов устройства, если в сохраненном логе имя отсутствовало (например, контакт записали уже после звонка).

---

## 6. Аккордеон повторных вызовов
- **Ответ на вопрос**: Нет, дублирование «не в белом списке» на каждой строке — это лишний визуальный шум, так как статус уже указан в шапке карточки.
- **Решение**: Убрать повторяющийся текст «не в белом списке» из аккордеона. Оставить только порядковый номер вызова и время (`#3 • 14:25`). Причину показывать только если она особая (например, «Скрытый номер»).
