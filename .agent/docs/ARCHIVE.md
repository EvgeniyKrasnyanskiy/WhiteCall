# Архив выполненных задач и контекста сессии

## Дата: 17 августа 2026

### Реализованный функционал проекта WhiteCall

1. **Базовое приложение и CallScreeningService**:
   - Полнофункциональное Android-приложение на Kotlin + Jetpack Compose + Room + Material Design 3.
   - Сервис `WhiteCallScreeningService` для бесшумного перехвата и фильтрации входящих звонков до включения экрана и звука.
   - Нормализация и строгое сравнение телефонных номеров с учетом международных форматов.
   - Поддержка переключения режима «Разрешить все контакты из книги».

2. **Папочная структура Белого списка (Группы)**:
   - Сущность `GroupEntity`, DAO `GroupDao`, репозиторий `WhiteListRepository`.
   - Экран белого списка организован в виде раскрывающихся **Папок (Групп)** с тумблерами активности (включение/отключение приема звонков от номеров группы).
   - Быстрое добавление контактов прямо внутрь нужной папки (вручную и из телефонной книги).
   - Автоматическое создание папки «Основная» при добавлении первого контакта.
   - Адаптивный статус «Контакты разрешены» при активном доступе к книге контактов.

3. **Режимы блокировки звонков (В настройках)**:
   - **Сброс вызова (абонент занят)**: вызов отклоняется на уровне сети, звонящий получает сигнал «Занято».
   - **Беззвучный режим (гудки звонящему)**: вызов изолируется от телефона (`setDisallowCall(true)`, `setRejectCall(false)`, `setSilenceCall(true)`), звонящий слышит длинные гудки, телефон полностью молчит и не отображает звонок в стандартной звонилке.

4. **Адаптивный виджет рабочего стола (от 2х1 до 5х2)**:
   - **Компактный режим 2х1 / 2х2**: заголовок `WC`, компактный бейдж `Блок: N`, кнопка питания `[ ⏻ ]`.
   - **Расширенный режим 3х1..5х1**: заголовок `WhiteCall`, статус защиты, бейдж `Блок: N`, кнопка питания.
   - **2-уровневый дашборд 5x2 / 4x2 / 3x2**:
     - Верхняя строка: `WhiteCall` (20sp) + статус защиты + кнопка питания `[ ⏻ ]`.
     - Средняя строка: статистика `Блок: День: N • Нед: W • Мес: M` • `👥 K` (контакты в белом списке).
     - Нижняя строка: карточка последнего заблокированного звонка или активный входящий вызов.
   - **Мигание зеленой трубки при звонке**: при поступлении неразрешенного звонка виджет отчетливо пульсирует зеленой трубкой с именем/номером звонящего в течение 10 секунд.
   - Кнопка питания переключает состояние защиты (зеленая / серая).
   - Ограничение максимальной высоты до 2 строк (`maxResizeHeight="115dp"`).

5. **Темы оформления и интерфейс**:
   - Переключение темы в «Настройках»: Системная / Темная / Светлая с мгновенным применением на лету.
   - Пастельные, мягкие тона для активных элементов в светлой теме (`#DCFCE7` / `#15803D`).
   - Четкие, контрастные переключатели Material 3 (`Switch`).

6. **Ограничение журнала и экспорт/импорт**:
   - Автоматическая очистка старых записей в базе данных с удержанием 500 последних вызовов (`trimOldRecords(500)`).
   - Мгновенное реактивное обновление статуса в журнале при добавлении в белый список («• В белом списке» с зеленой галочкой).
   - Экспорт и импорт базы в JSON (`JsonBackupHelper`) с сохранением структуры групп.
