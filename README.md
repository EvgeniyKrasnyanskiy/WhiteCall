# WhiteCall (White List Call Blocker)

WhiteCall — надежное Android-приложение на Kotlin для блокировки входящих звонков по принципу «Белого списка». Нежелательные звонки сбрасываются бесшумно на системном уровне до пробуждения экрана и звонка с помощью `CallScreeningService`.

## Основные возможности

1. **Блокировка на уровне ядра (CallScreeningService)**:
   - Автоматический сброс звонков от абонентов, не входящих в белый список.
   - Фильтрация скрытых/анонимных номеров.
   - Опция автоматического пропуска всех номеров из телефонной книги.
   - Отсутствие ложных срабатываний и бесшумный режим (телефон не загорается и не звонит).

2. **3-вкладочный интерфейс (Jetpack Compose & Material 3)**:
   - **Белый список**: быстрый поиск, удаление, добавление контактов через системный пикер контактов или ручной ввод с валидацией.
   - **Журнал блокировок**: детальный лог отклоненных вызовов с датой/временем, причинами и добавлением в белый список в 1 клик.
   - **Настройки и справка**: назначение роли по умолчанию, рубильник защиты, планировщик по часам и дням недели, переключатель языка (Системный/English/Русский), экспорт/импорт базы в JSON и руководство для OEM прошивок (Xiaomi MIUI/HyperOS, Samsung, Huawei).

3. **Интерактивный 2x1 AppWidget**:
   - Отображение текущего статуса защиты (Активно / По расписанию / Отключено).
   - Счетчик заблокированных вызовов за сегодня.
   - Мгновенное отображение последнего отклоненного звонка.
   - Быстрый переключатель защиты прямо с рабочего стола.

4. **Локализация (i18n)**:
   - Полная поддержка English и Русский.

## Архитектура и технологии
- **Kotlin 1.9+**, **Jetpack Compose + Material 3**
- **Clean Architecture + MVVM**
- **Room Database** (Белый список и журнал блокировок)
- **SharedPreferences / DataStore**
- **`android.telecom.CallScreeningService`**
- **AppWidgetProvider**
